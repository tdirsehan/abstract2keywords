# Abstract2Keywords

A lightweight academic web app for generating publication-oriented keywords from research abstracts.

Live app:
https://tdirsehan.github.io/abstract2keywords/

## What it does

- Accepts unstructured or structured abstracts
- Converts an unstructured abstract into Purpose, Design/methodology/approach, Findings, and Originality/value sections
- Tracks section-level and total word counts
- Generates between 1 and 10 keywords
- Ranks keywords primarily from repeated meaningful academic terms
- Excludes generic research words from keyword generation
- Allows one-click copying of generated keywords

The app runs entirely in the browser and is designed for GitHub Pages.
